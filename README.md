# ActionsExercise: podcast feed automation

A practice repo for **GitHub Actions**, GitHub's built-in automation. Actions are small robots that run a job automatically whenever something happens in a repo.

## What's here

The exercise comes from a LinkedIn Learning course. The goal is to turn a simple `feed.yaml` file into a podcast RSS feed automatically each time an episode is added.

- `feed.yaml` – the podcast's details (title, description, episode list)
- `TFIT01.mp3` – `TFIT05.mp3` – sample episodes from the course podcast "The Future in Tech"
- `artwork.jpg` – cover art

The automation workflow file (`.github/workflows/`) was never added, so this exercise isn't finished yet.
